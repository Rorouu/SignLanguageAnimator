SignLanguageAnimator
An interactive Unity-based application designed to animate sign language gestures.
The project aims to bridge communication gaps by providing an engaging and intuitive way to visualize sign language for learning, communication, and accessibility purposes.

Features
📚 Real-time sign language animation

🎮 User-friendly Unity environment

🔧 Easy to update and expand with new gestures

💬 Supports customizable animations for different sign languages

🎨 Designed for accessibility, education, and entertainment
